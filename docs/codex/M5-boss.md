# M5 괴식 마녀 보스

로열킹덤의 다크 킹 판, 쿠키런: 마녀의 성의 보스전처럼 「큰 적을 때려 눕히는」 판. M4까지 합쳐진 뒤 시작한다.

## 규칙

- 스테이지 5·10·15·20·25·30 을 보스 판으로 바꾼다(임무 종류 `boss`).
- 판 위에 괴식 마녀와 체력 막대. 지운 칸 1개 = 1, 특수 젤리·합체·탄산은 추가 피해(추천: 폭탄 6, 롤링핀 8, 합체 15, 마카롱 12).
- 마녀는 K수마다 큰 공격을 예고한다(머리 위 큰 숫자 카운트다운). 공격 종류(정해진 순서로 돌아가며):
  - 시럽 비: 빈 칸 3개에 시럽 예고(공정성 규칙 그대로)
  - 까마귀 부르기: 소중한 것 옆에 까마귀 예고
  - 설탕 뿌리기: 내 젤리 4칸에 설탕 예고
- 체력이 절반 아래면 공격 간격이 짧아지고 마녀가 화난 얼굴(위기 연출과 이어짐).
- 체력 0 = 승리. 수 제한은 없고 판이 막히면 패배(지금과 같음).

## 화면

- 판 위쪽에 마녀(캔버스로 그림, 이미지 파일 없음). 맞을 때 움찔·번쩍, 체력 막대가 줄며 깎인 만큼 흰 잔상.
- 공격 예고 때 마녀가 지팡이를 들고, 카운트가 1이면 화면 가장자리 보라색 맥박.
- 쓰러뜨리면 마녀가 젤리 범벅이 되며 날아가는 연출 + 「승리!」.
- 그림이 더 필요하면(마녀 얼굴 등) PR 에 「그림 필요」로 적는다. 그림은 작가 쪽에서 웹 ChatGPT로만 만든다.

## 밸런스

- 보스 판 깨는 비율(초보 / 익숙): 5 ≥ 30% / ≥ 90%, 10 ≥ 10% / 60~80%, 30 ≥ 1% / 25~45%.
