# M3 과자 기믹: 탄산 젤리 · 쿠키 상자

작가가 고른 두 가지. M2(특수 젤리·합체)가 합쳐진 뒤 시작한다.

## 탄산 젤리 (연쇄의 재료)

- 조각 칸에 가끔 「탄산」 조각이 나온다(조각 모양은 그대로, 칸마다 기포 무늬). 놓으면 판 위 탄산 젤리가 된다.
- 탄산 젤리가 지워지면 「퐁!」 하고 상하좌우 4칸을 같이 지운다(위협 해체·설탕·슬라임 깨기 포함). 터진 칸 중 탄산 젤리가 있으면 그것도 터진다(연쇄).
- 특수 젤리를 맞히면 특수 젤리도 터진다.
- 나오는 비율: 끝없이 2단계(20수)부터, 리필 조각 중 추천 12%. 스테이지는 임무에 따라 켬/끔 값을 둠. 무작위는 `rand(state)`.
- 공정성 검사(`canCoverCell`)는 조각 모양만 보므로 영향 없음. 그래도 `sim.js` 0건 확인.

## 쿠키 상자 (두 겹 장애물)

- 판 칸을 차지하는 상자. 줄 채우기에는 「찬 칸」으로 친다. 줄이 지워질 때 상자는 사라지지 않고 한 겹 깨진다(2겹 → 금 간 1겹 → 열림). 폭발·탄산·롤링핀에 맞아도 한 겹.
- 열리면 안에서 특수 젤리가 나온다(정해진 순서로 롤링핀 → 폭탄 → 마카롱 돌아가며).
- 중력: 상자는 떨어지지 않는다(받침 역할). 위의 젤리는 상자 위에 멈춘다.
- 어디서 나오나: 스테이지 시작 판에 미리 놓는 장애물(스테이지 정의에 칸 목록), 끝없이 3단계(40수)부터 가끔 위협 대신 「상자 배달」(빈 칸, 예고 1수 뒤 놓임, 덮을 수 있는 칸만 = 공정성 규칙 그대로).
- 스테이지 임무 종류 추가: 「쿠키 상자 N개 열기」.

## 화면

- 탄산: 칸 안에 올라가는 기포, 터질 때 사방으로 튀는 거품 + 「퐁」 소리.
- 쿠키 상자: 체크무늬 쿠키 상자, 금 가는 그림, 열릴 때 뚜껑이 날아가며 특수 젤리가 튀어나옴.
- 도감에 두 줄 추가. 처음 볼 때 한 번 안내 말.

## 시험

- 탄산 4칸 터짐, 탄산끼리 연쇄, 탄산이 특수 젤리를 터뜨림
- 상자 줄 채움 인정, 두 번 맞아 열림, 열리면 특수 젤리, 중력에서 고정
- 상자 배달 공정성, 결정론, 미리보기 = 실제

## 밸런스

- 기준선 대비 익숙 봇 끝없이 가운데값 ±20% 안, 새 스테이지 임무를 넣으면 곡선이 오르막이 되게.
