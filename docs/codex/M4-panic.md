# M4 패닉

목표: 판이 위험해지면 화면이 같이 떨고, 넘기면 숨이 트인다. 메뉴는 없다. 이 게임 이름이 왜 「젤리 패닉」인지 첫 판에서 느껴진다.
작가 방향: 쿠키런: 마녀의 성·로열킹덤처럼 직관적인 재미. 게이지·카드 고르기 같은 메뉴형은 쓰지 않는다.

## 1. 위기 단계 (core, 순수 함수)

- `dangerLevel(state)` → 0~3. 판을 바꾸지 않는다.
  - 다음 수에 터지는 위협 수, 소중한 것 옆 까마귀 예고, 놓을 수 있는 조각 칸 수(트레이 3개 중 놓을 곳이 있는 개수), 빈 칸 비율을 묶어 정한다.
  - 추천: 3 = 다음 수에 소중한 것이 잡히거나 놓을 수 있는 조각이 1개 이하 / 2 = 다음 수에 터지는 위협 2개 이상 또는 빈 칸 25% 이하 / 1 = 다음 수에 터지는 위협 1개 또는 빈 칸 35% 이하 / 0 = 그 밖.
- 시험: 각 단계를 만드는 판을 직접 짜서 확인.

## 2. 위기 연출 (ui)

| 단계 | 화면 | 소리 | 소중한 것 |
|---|---|---|---|
| 1 | 판 테두리가 옅게 주황 | 배경 박자 조금 빨라짐 | 땀방울, 눈 굴림 |
| 2 | 화면 가장자리 붉은 맥박(심장 박동 간격) | 심장 소리 「두근」 | 덜덜 떨림, 「으앙」 표정 |
| 3 | 붉은 맥박 강하게 + 위에 「패닉!」 글자가 흔들림 | 심장 빨라짐 + 경보음 짧게 | 울면서 마스코트 쪽을 봄 |

- 흔들림 줄이기 켜면: 맥박은 색만 바뀌고 움직임 0.
- 위협 예고 숫자도 위기 단계 2 이상이면 크게·빨갛게.

## 3. 위기 넘김 「휴!」

- 위기 단계가 2 이상이었다가 한 수 만에 0~1로 내려오면: 화면이 확 밝아지고 「휴~ 살았다!」 큰 글자, 소중한 것 안도 표정, 보너스 점수(추천 +50, core 규칙으로).
- 판마다 이 순간이 몇 번 오는지 재서 PR 에 붙인다(익숙 봇 평균, 초보 봇 평균). 목표: 익숙 봇 판당 2회 이상.

## 4. 마스코트 스킬 「젤리 펀치」 (쿠키런식 한 번 누르기)

- 왼쪽 위 마스코트에 게이지 링. 줄을 지울 때마다 찬다(추천: 지운 칸 1개 = 1, 24 = 가득).
- 가득 차면 마스코트가 빛나며 통통 튐. 누르면 바로 발동(조각 놓기와 별개, 위협 시간은 흐르지 않음).
- 효과(결정론): 가장 급한 위협 하나를 골라(소중한 것 옆 까마귀 > 남은 수가 적은 것 > 위→아래, 왼→오) 그 칸 중심 십자 한 줄씩(행 + 열) 지움. 위협 해체·설탕/슬라임 깨기·구출은 아이템과 같은 처리.
- 위기 단계 2 이상일 때 게이지가 가득이면 마스코트가 더 크게 빛나고 손가락 안내 1회(기기마다 처음 3번).
- 오늘의 임무에서도 같음(모두 같은 규칙이라 공정).
- `window.CORE` 에 `useSkill(state)` 추가(기존 API 유지), `previewSkill(state)` 로 화면이 누르기 전에 범위를 보여 줌(마스코트를 누르고 있으면 범위 표시, 떼면 발동).
- 지연 벨(판당 1번)은 그대로 둔다.

## 밸런스

- 스킬 때문에 쉬워지는 만큼 스테이지 임무 크기를 다시 맞춘다. 목표(초보 / 익숙): 스테이지 10 ≥ 10% / 55~75%, 스테이지 30 ≥ 1% / 25~45%, 오늘의 임무 ≥ 45% / ≥ 90%.
- 봇에 「스킬이 차면 위기 단계 2 이상일 때 쓴다」 규칙을 넣어 잰다(`tools/balance.js`).
