# M2 특수 젤리와 합체

목표: 아이템이 조각 칸이 아닌 **판 위**에 「특수 젤리」로 생기고, 줄에 걸리면 터지고, 둘이 붙어 있으면 합체해서 더 크게 터진다. 로열킹덤의 「부스터 둘을 맞붙이면 합체」를 놓기 퍼즐에 옮긴 것. 설명 없이 한 번 보면 따라 할 수 있어야 한다.

M1(손맛)이 합쳐진 뒤 시작한다. M1 연출 함수를 그대로 써서 터짐·합체를 크게 보여 준다.

## 규칙 (core)

### 특수 젤리
- 판 칸에 「특수」 겹을 하나 더 둔다. 추천: `state.special[r][c] = null | 'rollH' | 'rollV' | 'bomb' | 'macaron'`. 칸 자체는 `BLOCK`(맛 색 유지)이라 줄 채우기·중력에서 보통 젤리와 똑같이 움직인다(떨어질 때 특수 겹도 같이 이동).
- 종류: 가로 롤링핀(그 행 전부), 세로 롤링핀(그 열 전부), 폭탄(3×3), 마카롱(판 위 같은 맛 젤리 전부).
- 터지는 때: 그 칸이 줄 지우기로 지워질 때, 또는 다른 폭발에 맞을 때. 터지는 범위 안의 다른 특수 젤리도 터진다(연쇄).
- 터질 때 칸 처리는 지금 아이템과 같다(`itemClearCell`: 위협 예고 해체, 설탕·슬라임 깨기, 소중한 것 구출, 디펜스 보호 대상은 그대로).

### 생기는 조건 (추천값, 밸런스 측정으로 조정 가능)
- 한 수에 2줄을 동시에 지움 → 롤링핀 젤리(지운 줄이 가로면 가로, 세로면 세로, 섞이면 놓은 조각 모양 기준으로 정함)
- 연쇄 2단 이상 → 폭탄 젤리
- 한 수에 3줄 이상 → 마카롱 젤리
- 소중한 것 구출 → 마카롱 젤리
- 생기는 자리: 방금 놓은 조각 칸 중 남아 있는 칸. 다 지워졌으면 놓은 조각의 기준 칸에 새 젤리로 생김(그 칸이 비어 있을 때. 아니면 가장 가까운 빈 칸, 정해진 순서로).
- 지금의 「조각 칸 아이템 지급」(2연쇄 → 폭탄, 3줄 → 롤링핀, 구출 → 마카롱)은 위 규칙으로 바꾼다. 조각 칸 아이템은 연속 완수 보상·디펜스 보급처럼 따로 주는 것만 남는다.

### 합체
- **붙어 있는 두 특수 젤리** 중 하나가 터지면, 상하좌우로 붙은 특수 젤리와 합체해 아래 효과가 한 번에 난다(가운데 = 나중 것 자리).
- **조각 칸 아이템을 판 위 특수 젤리에 놓으면** 그 자리에서 바로 합체.

| 합체 | 효과 |
|---|---|
| 롤링핀 + 롤링핀 | 그 자리 행 + 열 (십자) |
| 롤링핀 + 폭탄 | 그 자리 중심 3행 + 3열 (굵은 십자) |
| 폭탄 + 폭탄 | 5×5 |
| 마카롱 + 롤링핀 | 판에서 가장 많은 맛 젤리가 전부 롤링핀(가로·세로 번갈아)이 되었다가 차례로 터짐 |
| 마카롱 + 폭탄 | 가장 많은 맛 젤리가 전부 폭탄이 되었다가 차례로 터짐 |
| 마카롱 + 마카롱 | 판의 젤리·위협 칸 전부 지움(소중한 것은 구출, 구멍은 그대로) |

- 합체·연쇄 터짐은 결정론. 순서는 「가까운 것부터, 같으면 위→아래, 왼→오」.
- `previewPlace` 가 터짐·합체까지 그대로 보여 줘야 한다(화면에서 놓기 전에 터질 범위가 노랗게 보이는 지금 방식 유지).

## 화면 (ui)

- 특수 젤리는 맛 색 젤리 위에 표시: 롤링핀 = 방향 줄무늬 + 작은 롤링핀, 폭탄 = 심지 불꽃, 마카롱 = 무지개 테두리. 은은하게 숨 쉬듯 반짝여서 판에서 바로 눈에 띔. 맛 무늬(♥▲●≈★)와 겹치지 않게.
- 붙어 있는 특수 젤리 둘 사이에 작은 번개 선 → 「붙이면 합체」를 말없이 알려 줌.
- 합체 순간: 두 젤리가 빨려 붙는 짧은 연출(120ms) → 큰 멈칫(140ms) → 효과. 외침 「합체!」, 마카롱 합체는 「젤리 패닉!!」.
- 처음 특수 젤리가 생기면 한 번만: 「특수 젤리! 줄에 넣으면 터져요」, 처음 둘이 붙으면: 「붙어 있으면 합체해요」.
- 도감: 특수 젤리 4종, 합체 표를 그림 6칸으로.
- `?fxdemo=1` 에 합체 6종 추가.

## 밸런스 목표 (`node tools/balance.js --compare docs/codex/baseline.json`)

- 초보 봇 스테이지 깨는 비율: 4 ≥ 35%, 7 ≥ 15%, 10 ≥ 5% (지금 25 / 7 / 0)
- 초보 봇 오늘의 임무 ≥ 40% (지금 33%)
- 익숙 봇 스테이지 30 = 25~45%, 익숙 봇 끝없이 놓은 수 가운데값 = 90~170
- 너무 쉬워지면 생기는 조건이나 스테이지 임무 크기를 조정(`STAGES`·`DAILY_TEMPLATES` 숫자 변경 허용, 이유를 PR 에 적기). 위협 규칙은 건드리지 않는다.
- 새로 재서 PR 에 붙일 것: 익숙 봇 한 판 평균 특수 젤리 생김 수·합체 수, 초보 봇 첫 특수 젤리까지 놓은 수 가운데값. `tools/balance.js` 에 이 집계를 더해도 된다.
