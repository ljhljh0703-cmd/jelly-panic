# 젤리 패닉 2차 디벨롭 로드맵 (2026-10-25)

작가 요청: 「로열킹덤처럼 이펙트·타격감을 더 크게, 젤리·과자를 쓴 다양한 조합과 기믹, 이름값 하는 패닉. 쿠키런: 마녀의 성·로열킹덤처럼 직관적인 재미로.」
역할: 구현 = Codex, 목표·방향·검수 = Claude, 합치기 결정 = 작가.

## 목표

1. **한 번 지울 때마다 손이 짜릿하다.** 줄 하나 지우는 것도 멈칫·파편·소리가 겹쳐 「터졌다」가 느껴지고, 많이 지울수록 확실히 더 크다.
2. **아이템끼리 붙이면 더 큰 게 터진다.** 판 위에 생긴 특수 젤리끼리 맞물리면 합체해서 터지고, 그게 연쇄를 부른다. 설명 없이 보고 따라 할 수 있다.
3. **판이 위험해지면 화면이 같이 떨고, 넘기면 숨이 트인다.** 메뉴를 열지 않는다. 소중한 것이 겁먹고, 화면이 붉게 뛰고, 마스코트 한 번 누르기로 위기를 넘기는 순간이 판마다 몇 번 온다. 그래서 이름이 「젤리 패닉」이다.
4. **처음 하는 사람도 뒤 스테이지까지 간다.** 지금 초보 봇은 스테이지 4부터 25%, 7부터 10% 밑, 10부터 0%. 오늘의 임무도 33%. 조합·스킬로 손에 쥘 도구가 늘어 이 숫자가 오른다.

## 참고한 것 (방향만, 그대로 베끼지 않음)

- 로열킹덤·로열매치: 특수 블록끼리 맞붙이면 합체(로켓+로켓 = 십자, 로켓+TNT = 3줄 십자, 라이트볼+X = 그 색 전부 X로). 보스(다크 킹)를 치는 판.
- 쿠키런: 마녀의 성: 블록 터질 때 시각 효과에 공을 들인 쾌감, 쿠키마다 스킬(정해진 모양으로 타격 / 무작위 다수 타격)로 막힌 곳을 뚫음, 보스마다 고유 기믹.

## 단계 (한 단계 = PR 하나, 앞 단계가 합쳐진 뒤 다음 단계)

| 단계 | 이름 | 핵심 | 지시 파일 |
|---|---|---|---|
| M1 | 손맛 | 멈칫·화면 펀치·젤리 파편·연쇄 외침·소리 겹침, 흔들림 줄이기 설정 | `M1-juice.md` |
| M2 | 특수 젤리와 합체 | 아이템이 판 위 특수 젤리로 생기고, 줄에 걸리면 터짐, 둘이 맞물리면 합체 | `M2-combos.md` (M1 진행 중 작성) |
| M3 | 과자 기믹 | 탄산 젤리(터지며 옆 칸까지), 쿠키 상자(두 겹, 깨면 특수 젤리) | `M3-snacks.md` |
| M4 | 패닉 | 위기 단계 연출(소중한 것 겁먹음·붉은 맥박·심장 소리), 위기 넘김 「휴!」 보너스, 마스코트 스킬 한 번 누르기 | `M4-panic.md` |
| M5 | 괴식 마녀 보스 | 5·10·…스테이지가 보스 판: 체력 막대, 예고하고 크게 때리는 공격 | `M5-boss.md` |

작가가 고른 것: 타격감 = 로열킹덤급 + 흔들림 줄이기 설정, 과자 기믹 = 탄산 젤리·쿠키 상자, Codex 연결 = GitHub. 패닉은 메뉴형(게이지·카드, 홍수)을 거절하고 「직관적인 재미」로 정함 → 위 3번.

## 숫자 기준선 (2026-10-25, `node tools/balance.js` → `baseline.json`)

- 끝없이: 초보 봇 놓은 수 가운데값 45, 익숙 봇 114
- 스테이지 깨는 비율(초보 / 익숙): 1 75/99 · 4 25/93 · 7 7/91 · 10 0/62 · 20 0/50 · 30 0/35
- 오늘의 임무: 초보 33%, 익숙 94%
- 공정성: 무작위 500판 회피 불가능한 스폰 0건

단계마다 이 숫자를 다시 재서 PR 에 붙인다. M2·M4 이후 목표: 초보 봇 스테이지 4~10 이 지금보다 확실히 오름(단계별 지시에 숫자로 적음), 익숙 봇 스테이지 30 은 25~45% 사이 유지.

## 검수 (Claude)

PR 이 올라오면 Claude 가 한다: 시험·공정성·밸런스 재실행, 폰 크기 화면 녹화·캡처로 연출 확인, 지시 파일 기준표 대조. 고칠 것은 PR 댓글로 `@codex` 에게 다시 맡긴다. 다 맞으면 작가에게 「합쳐도 됨」으로 올린다.
