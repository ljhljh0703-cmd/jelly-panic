# M1 손맛 (타격감·이펙트)

목표: 줄 하나를 지워도 「터졌다」가 손에 오고, 많이 지울수록·연쇄가 길수록 확실히 더 크다. 로열킹덤급. 규칙은 그대로 두고 화면·소리·진동만 바꾼다.

## 범위

- 고치는 곳: `src/ui.js`(연출), `index.html`(CSS·설정 단추 자리). `src/core.js` 는 연출에 필요한 이벤트 값을 **더하기만** 할 수 있다(규칙·점수·무작위 순서 변화 0).
- 지금 연출이 있는 곳: `juice(ev)`(이벤트 → 연출), `addFlash / addSparkles / addFloat / drawFx`, `sfx(kind)`, `buzz(ms)`, `shakeT`, `vignetteT`, `cellPop`, `fallAnim`.
- 밸런스 숫자는 하나도 바뀌면 안 된다: `node tools/balance.js --quick --compare docs/codex/baseline-quick.json` 전부 `(=)`.

## 만들 것

1. **멈칫(히트스톱)**: 줄이 지워지는 순간 판 그림(파편·낙하·위협 맥박)을 잠깐 멈춘다. 1줄 45ms · 2줄 70ms · 3줄 이상 100ms · 연쇄 한 단계마다 +15ms(최대 140ms) · 폭탄 90ms · 롤링핀 70ms · 마카롱 80ms. 멈춘 동안 들어온 손 입력은 버리지 않는다(멈춤이 끝나면 처리).
2. **화면 펀치·흔들림**: 2줄 이상이면 판이 1.035배로 커졌다 돌아온다(160ms). 흔들림 세기: 1줄 0 · 2줄 3px · 3줄 이상 6px · 폭탄 8px. 롤링핀은 굴러가는 방향으로만 흔든다. 지금 `shakeT` 고정값을 세기·방향을 받는 함수로 바꾼다.
3. **줄 쓸기**: 지워지는 줄을 따라 하얀·금빛 빛줄기가 180ms 동안 지나가고(가로 줄은 왼→오, 세로 줄은 위→아래, 놓은 조각 쪽에서 시작), 칸들이 빛줄기가 지나는 순서대로 1.15배로 부풀었다 사라진다.
4. **젤리 파편**: 지운 칸마다 그 맛 색의 말랑한 젤리 조각 5~7개가 튀어 오르고, 중력으로 떨어지며 판 아래 끝에서 한 번 튕긴 뒤 사라진다. 조각은 둥근 덩어리 + 작은 하이라이트, 돌면서 찌그러짐. 설탕 부스러기 2개 섞기. 파편 상한 400개, 미리 만든 배열을 다시 쓴다(프레임마다 새 객체 만들지 않기).
5. **연쇄 외침**: 판 가운데에 큰 글자. 연쇄 2 「달콤!」 · 3 「짜릿!」 · 4 「환상!」 · 5 이상 「젤리 패닉!!」, 한 번에 3줄 이상 「한입에 쏙!」. 0.4배 → 1.15배 → 1배로 튀어나오고 위로 떠오르며 700ms 뒤 사라짐. 겹치면 새 것이 이긴다. 글자에 흰 테두리, 연쇄가 클수록 색이 분홍 → 주황 → 빨강.
6. **점수 숫자**: 연쇄가 길수록 크게(20px → 연쇄 5 이상 34px). 위 점수판 숫자도 올라갈 때 통 튀기.
7. **아이템 연출 키우기**: 폭탄 = 충격파 고리 2겹 + 큰 파편 + 낮은 쿵. 롤링핀 = 굴러가는 롤링핀 그림이 줄을 따라 지나가며 칸을 민다. 마카롱 = 같은 맛 칸들이 마카롱 쪽으로 빨려 들어가며 사라짐.
8. **막았을 때·구했을 때**: 위협을 덮어 막으면 그 칸에 방패 반짝 + 「막음!」 작은 글자. 소중한 것을 구하면 하트·색종이 폭죽 + 마스코트 환호(지금 것보다 크게).
9. **소리 겹치기**: 지울 때 낮은 「쿵」(70~90Hz, 120ms) + 가운데 「퐁」 + 높은 「반짝」. 빛줄기에 「슉」. 연쇄 단계마다 음이 올라감(지금 것 유지). 전체 소리 끝에 압축기(DynamicsCompressor)를 달아 겹쳐도 깨지지 않게.
10. **진동**: 1줄 약하게, 2줄 이상 강하게, 폭탄은 짧게 두 번. 토스에서는 `PLATFORM.haptic` 그대로 씀.
11. **흔들림 줄이기 설정**: 도감 「맛 무늬」 줄 아래에 「흔들림 줄이기」 켜짐/꺼짐 단추(같은 모양). 저장 키 `cp-calm`. 처음 값은 기기의 `prefers-reduced-motion` 을 따름. 켜면: 흔들림·펀치 0, 멈칫 최대 40ms, 번쩍임 투명도 절반, 파편 절반.
12. **검수용 시연 `?fxdemo=1`** (`[RELEASE-STRIP]` 구간 안에, `node tools/build.js --dev dev.html` 로 만든 사본에서 열림): 열면 2초 간격으로 1줄 → 2줄 → 3줄 → 연쇄 3 → 연쇄 5 → 폭탄 → 가로 롤링핀 → 마카롱 → 위협 막기 → 소중한 것 구출을 차례로 보여 준다(판을 직접 짜서 `doPlace` 로). `?fxdemo=1&calm=1` 이면 흔들림 줄이기 켠 상태로.

## 하지 않을 것

- 규칙·점수·위협·아이템 지급 조건 바꾸기 (M2 이후)
- 그림 파일 추가, 외부 소리 파일 (소리는 지금처럼 WebAudio 로 합성)
- 판 밖 화면 배치 바꾸기
